= Inicio rápido para NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
Descubre cómo configurar NetApp Disaster Recovery, asegurándote de que tu sistema cumpla los requisitos necesarios para detectar correctamente las cargas de trabajo y configurar planes de replicación con el fin de prepararte para la conmutación por error.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]Revisar los prerrequisitos
[role="quick-margin-para"]
Necesitas el rol de _Super admin_ o _Organization admin_ para implementar un agente de Console y asignar permisos.

[role="quick-margin-list"]
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["Despliega un agente de consola"^]
* link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Revisa los roles de usuario de NetApp Disaster Recovery y asigna permisos a los usuarios que los necesiten"^]
* link:../get-started/dr-prerequisites.html["Asegúrese de que su sistema cumpla estos requisitos"]
* Asegúrate de cumplir los requisitos correspondientes al tipo de carga de trabajo que tengas:
+
** link:../get-started/reference-vmware-prerequisites.html["Requisitos previos de VMware"]
** link:../get-started/task-kubernetes-requirements.html["Requisitos previos de Kubernetes"]
