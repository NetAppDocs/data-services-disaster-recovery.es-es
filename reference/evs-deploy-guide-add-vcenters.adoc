= Agregue clústeres locales y de Amazon EVS vCenter en NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Después de crear los sitios, añade los clústeres de vCenter para cada sitio en NetApp Disaster Recovery. El tipo de sitio determina el acceso que NetApp Disaster Recovery requiere para los vCenters en ese sitio. Amazon EVS vCenters y los vCenters locales usan la misma información de conexión y autenticación.

.Pasos para agregar un vCenter a cada sitio
. Desde la opción *Sitios*, seleccione *Agregar vCenter* para el sitio que desee.
+
image:evs-add-vcenter-1.png["Agregar opción vCenter"]

. En el cuadro de diálogo Agregar servidor vCenter, seleccione o proporcione la siguiente información:
+
.. El agente de NetApp Console alojado dentro de su VPC de AWS.
.. La dirección IP o FQDN del vCenter que se agregará.
.. Si es necesario, cambia el puerto al puerto TCP que utilice tu servidor de vCenter.
.. El nombre de usuario de vCenter para la cuenta creada anteriormente que NetApp Disaster Recovery utilizará para administrar vCenter.




. Si tu organización utiliza una autoridad de certificación (CA) externa o el almacén de certificados de endpoint de vCenter, desmarca la casilla *Usar certificados autofirmados*. De lo contrario, deja la casilla marcada.
+
.. Seleccione *Agregar*.
+
image:evs-add-vcenter-2-3.png["Cuadro de diálogo Agregar vCenter"]
