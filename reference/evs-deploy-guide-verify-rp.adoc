= Verifique que todo funcione en NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Después de añadir un plan de replicación en NetApp Disaster Recovery, verifica que el plan esté en el estado *Healthy* antes de continuar.

Figura: Página de planes de replicaciónimage:evs-replication-plan-post-create.png["Página de planes de replicación"]

NetApp Disaster Recovery ejecuta una serie de pruebas para verificar que todos los componentes, incluidos el clúster de ONTAP, los clústeres de vCenter y las máquinas virtuales, sean accesibles y estén listos para la protección. Esto se llama comprobación de conformidad y se ejecuta de forma regular.

La página «Planes de replicación» muestra la siguiente información:

* Estado de la última verificación de cumplimiento
* El estado de replicación del plan de replicación
* El nombre del sitio protegido (fuente)
* La lista de grupos de recursos protegidos por el plan de replicación
* El nombre del sitio de conmutación por error (destino)
